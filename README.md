# CANIFA SCORM content

Gói SCORM đã import cho CANIFA Learning Hub, phục vụ qua GitHub Pages.
Mỗi thư mục là một gói (`<mã-gói>/`), có thêm `canifa/launcher.html` và runtime scorm-again.
Chỉ chứa nội dung bài học, không chứa dữ liệu học viên.

Thêm gói: `node tools/scorm-import.cjs <gói.zip> <mã-gói> <thư mục repo này>` trong repo Learning Hub.
